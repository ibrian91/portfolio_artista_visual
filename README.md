# PORTFOLIO Artista Visual

Para iniciar el proyecto se debe instalar dependencias en la carpeta FRONTEND y BACKEND.

Luego, con los archivos .env correspondientes, hacer npm run dev en cada uno (FRONTEND Y BACKEND).

Iniciar base de datos MySql, puede ser local con tu ide favorito y probar conexion aqui:

http://localhost:5000/api/upload/test-db

Debe retornar conexion exitosa y la fecha de la conexion.
